# Render free demo deployment

Use `render-free.yaml` for a $0/month demonstration deployment within
Render's included free limits. It contains:

- one free Static Site for the React frontend;
- one free Web Service running the Fastify gateway and the real provider
  simulator in the same process; and
- one free Render Postgres database.

The provider simulator listens on `127.0.0.1:3001` inside the Web Service.
It is not published as a second Render service or exposed publicly. The
gateway still calls the actual provider HTTP routes through
`http://127.0.0.1:3001`; no payment or recovery data is simulated by the UI.

## What works

- Real payment creation through `POST /payments`.
- Same-key idempotency retries.
- Same-key payload-conflict responses.
- Gateway `/health` and `/metrics`.
- The real in-memory provider charge behavior, including its configured
  simulated failures and timeouts.
- Local execution of all three recovery workers remains unchanged.

## What remains local

The three recovery workers are intentionally omitted from this free Blueprint:

- uncertain-payment recovery;
- provider-conflict resolution; and
- orphaned-webhook recovery.

They remain fully implemented and runnable locally with the existing worker
commands. Automatic recovery is therefore not available in the hosted free
demo.

## Required values

Render prompts for:

- `VITE_API_BASE_URL`: the public URL of `payment-gateway-free-demo`;
- `CORS_ORIGIN`: the public URL of `payment-reliability-playground-free`.

`DATABASE_URL` is populated from the same-region Render Postgres instance and
`WEBHOOK_SECRET` is generated by Render. Never place either secret in a
frontend `VITE_*` variable.

## Limitations and cost

This is genuinely $0/month only while the account remains within Render's
included free usage. Free Web Services can spin down after inactivity, so the
first request after idle time may be slow. Free Postgres is limited and expires
after 30 days; it has no backups. The provider's state is in memory and is
lost whenever the Web Service restarts or spins down.

The existing `render.yaml` remains the complete deployment with the provider
Private Service and three paid recovery workers. Do not replace it with this
demo Blueprint when deploying the full architecture.
